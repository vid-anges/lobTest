TRx Heading

Current Notch Heading

Compass heading the transceiver's notch is pointing to right now (0° = notch points true North). Northinfo (ring/needle rotation) is computed as 360° − TRx Heading. Changing this re-projects every monitored signal below to keep its true bearing fixed.

Signals Being Monitored

Each signal records the TRx Heading and AoA at the moment it was captured. Labels (M1, M2, ...) are assigned automatically and are never reused, even if a signal is removed. Compass at capture defaults to N/A, which links that signal to the live TRx Heading (its AoA always reads relative to the current notch). Type a fixed heading instead to snapshot that signal to a specific past orientation.

Visual Guide
Fixed Notch (Top): Fixed 12 o'clock reference marker (0° reference) pointing UPWARDS. TRx Heading and each signal's captured AoA are measured from here.
Red Needle: Points towards true North, at the computed Northinfo angle.
Grey Needle: Opposite indicator (South).
Colored Arrows: One per monitored signal, labeled (M1, M2, ...) at the tip. Each arrow re-projects to keep pointing at the same true bearing as TRx Heading changes.
